# 跨源复述必须有实质新增才能再次入选

同一事件可能先由官方或一手信源入选，几天后又被另一媒体用新 URL、新标题重新报道。既有跨日 URL 去重只能识别同一文档；事件登记表虽然知道两条报道属于同一事件线，连续性门却发生在选材完成之后，只负责验证可信延续，不能追回已经占用的精选或次级位置。

决定在读者可见选材阶段增加独立的**跨日实质新增门**。它与同日归并共享稳定循环：选位后执行同日读者可见归并、凝聚度重审和跨日实质新增检查；任一检查移除或合并条目后重新选位，只审尚未判定的新补位者，直到集合稳定。动态分数账本写入失败并切换静态阈值时，使用剩余预算重跑同一循环，不能让补位者绕过检查。

门只在同类目、最近 60 天的事件登记表中召回候选线，每条当前候选最多提供 6 条事件线。只有严格早于当前产出日、且至少含一条历史 `pick-*` 记录的线可以阻止再次精选：既往 `more-*`、仅存在于全部动态的事件，以及同日重跑已经写入的当前条目，都不能阻止它首次入选或把它判成自己的复述。每条线提供首条、最新条和最多 5 条最相关历史，优先通过 `item_ref` 回读既有日报中的已发布证据；不得联网补证据，也不得依赖模型记忆。批次同时受 20 条和 64,000 字符双重上限约束，单条证据仍超限时 fail-open，避免上下文溢出把整批变成无效响应。

模型只可返回 `different_event`、`material_addition`、`restatement` 或 `uncertain`。只有当前报道与历史属于同一事件、历史证据明确覆盖当前核心事实、且没有**实质新增**时才抑制 `restatement`。实质新增包括新结果、关键数字或影响范围变化、政策结论、正式更正，以及首次官方确认或否认导致可信状态变化；换来源、换标题、背景或参数解释、评论分析和重复基准结果不算。历史证据不足、类别不同、身份不确定、出现无法对齐的新事实或模型返回 `uncertain` 时都保留。

模型调用或响应结构不可信时 fail-open。输出必须恰好覆盖输入索引，且索引不得重复、越界，枚举和值类型必须合法；结构非法只在本门预算内重试一次。异常、漏项、重复或越界索引、非法枚举、重试失败和预算耗尽都保留候选，同时记录降级。默认每批 20 条，整次最多 8 次调用。

算分与选位分离：同日归并后的完整 `all_scored_events` 全部正常算分，用于全部动态回填和 `source_health.scored_events`；排除已确认跨源复述后的 `eligible_events` 才用于精选、次级和 `score_history.json`；最终 `picked` 才进入日报、事件登记和 `source_health.selected_events`。因此跨源复述仍可在全部动态检索，但不会再次占用读者可见位置或污染动态阈值。

跨日实质新增门返回非序列化的事件线提示。对保留的实质新增，该提示只能提高后续事件线召回优先级；连续性门仍独立决定是否续接。提示可把 60 天窗口内的归档线送入连续性门，但只有验证通过才续接并重新激活，拒绝后仍按新事件处理。被抑制的跨源复述不会进入连续性门，所以连续性门不复核抑制决定。两道门分别解决“是否值得再次入选”和“是否可以可信地续接事件线”。

## Considered Options

- **继续只按 URL 跨日去重**：不会误伤不同事件，但新 URL 可以无限绕过，无法解决跨源复述。
- **把连续性门提前并兼作去重**：混合“是否同一事件”和“是否有新信息”两个问题，也会让连续性门承担选材职责，破坏 ADR 0002 的独立信任边界。
- **只检查第一次选出的集合**：被抑制后出现的补位者会绕过检查；动态阈值失败后的静态回退也会产生同样漏洞。
- **审计失败时抑制可疑候选**：能减少重复，但会因模型或历史证据故障误删真正的新事件。日报允许偶发复述，不能接受静默漏掉实质新增。
- **历史次级也阻止精选**：会让从未得到精选位置的事件永久失去首次精选机会，与去重目的不相称。

## Consequences

- 跨源复述仍保存在 `all/YYYY-MM-DD.js` 和 `news-seen/YYYY-MM-DD.json`，并保留正常分数；精选、次级、事件历史和动态分数账本不再记录它。
- `quality-health.json` 新增七个可选诊断字段：候选、实质新增、跨源复述、失败、调用、延后和预算耗尽。公开日报 `quality`、前端和 API 不变；首版指标不参与 rollout 阻断。
- 事件登记表的 60 天保留期同时成为跨日实质新增门的记忆上限。超过保留期后不会匹配，这是有界成本与长期遗忘之间的明确取舍。
- `daily_news.py` 与运行配置变化会改变 rollout 运行时指纹；下一次有效发布重新起算相关验收窗口。
- 历史定点修复不得伪造运行遥测：删除错误精选时可同步修正日报、事件登记、分数账本、信源入选数、RSS 和搜索索引，但不回写当日公开 `quality`、`quality-health.json`、生成时间或简报文案。
